## Object-Oriented Programming (OOP)

### Introduction to OOP

Object-Oriented Programming is a programming approach based on classes and objects. It helps make code reusable, organized, and easy to maintain.

### OOP Concepts

1. Class
A class is a blueprint used to create objects.

2. Object
An object is an instance of a class.

3. Encapsulation
Encapsulation is the process of wrapping data and methods into a single unit (class) and controlling access to data.

4. Inheritance
Acquiring the properties (data) and behaviour(methods) from one class to another class.

Types of Inheritance in Python
There are 5 types of inheritance in Python:

1.Single level Inheritance : one child class inherits from one parents class
2.Multiple level Inheritance :one child inherits from multiple parents
3.Multilevel level Inheritance: a child inherits from parents, and that acts as a parent for another
4.Hierarchical level Inheritance: multiple childrens inherits from a single parent
5.Hybrid level Inheritance : Hybrid inheritance is a combination of two or more types of inheritance in a single program.


5. Polymorphism
Polymorphism allows the same method name to perform different tasks depending on the object.

6. Abstraction
Abstraction hides internal implementation details and shows only essential features.
